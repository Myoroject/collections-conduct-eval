# Cases

The fifty-five scenarios described in docs/02-evaluation-design.md, in the format
defined in schema/scenario.md.

Two samples are included to show the format in use: D7 in
third-party-disclosure.json and T2 in contact-timing.json. Each file holds a JSON
array of scenarios. The rest are not yet populated.

The scenarios exist in prose in the design paper; converting
them to the machine-readable format is the next task, and should be done after
the non-banking financial company paragraph numbers are enumerated, so that each
case carries the citation that actually applies to the deployment being tested.

Naming: one file per category, for example third-party-disclosure.json.
